# Bundled Noto Sans JP

The app bundles the unmodified static Regular font from the Noto CJK Sans 2.004 release:

- Source: https://github.com/notofonts/noto-cjk/blob/Sans2.004/Sans/SubsetOTF/JP/NotoSansJP-Regular.otf
- File: `NotoSansJP-Regular.otf`
- Version: 2.004
- Copyright embedded in the original font: © 2014–2021 Adobe (http://www.adobe.com/).
- License: SIL Open Font License 1.1, reproduced in `NotoSansJP-OFL.txt`.
- SHA-256: `dff723ba59d57d136764a04b9b2d03205544f7cd785a711442d6d2d085ac5073`

This is an OSS font obtained from the Noto project. It is not extracted from Acrobat or another proprietary application. The static font replaces the variable font used in versions 0.1–0.4. PDF exports embed the complete font because fontkit subsetting produced corrupt glyph outlines with both font formats.
